# AI Lab · 집계 수강 패턴 대시보드

메인 페이지: `al_lab.html`. Vercel 기본 주소 `/`는 `vercel.json` rewrite로 연결됩니다.

## 데이터 경계
이 저장소에는 **집계값만** 포함합니다. 연구 원자료, 가명 학생 기록, 학생 좌표, 학생별 추정 확률은 올리지 않습니다. 집계 지도는 각 원이 5명 이상인 집단입니다. 서로 다른 학기의 집단에 학생별 연결 정보는 없습니다. 개별 학생 지도와는 표현이 다릅니다.

## 수정과 배포
1. `app.js`, `styles.css`, `al_lab.html` 또는 집계 `data.json` 수정.
2. `node check-public.cjs` 실행.
3. `CHANGELOG.md`에 변경 내용을 추가하고 `package.json` 및 `data.json` 버전 갱신.
4. 변경을 Git 커밋으로 저장. 화면 변경은 `codex/설명` 브랜치에서 미리보기 후 기본 브랜치 반영.
5. Vercel에 연결된 기본 브랜치에 push하면 자동 배포됩니다.
6. 문제 발생 시 이전 Git 커밋을 revert하거나 Vercel 이전 배포를 복원합니다.

## 원자료 갱신 — 로컬 컴퓨터에서만
`node export-aggregates.cjs <비공개 HTML 템플릿 경로> <비공개 결과 HTML 경로> <수정 문구 JSON 경로>`

이 명령은 로컬 원자료를 읽고 검증된 `data.json`만 생성합니다. 원본 경로와 파일은 저장소 외부에 둡니다. Vercel 빌드에서 원자료를 읽거나 업로드하지 않습니다.

개별 집단 5명 미만 통계 및 5명 미만이 수강한 과목별 집계는 공개하지 않습니다. 생략된 과목도 전체 비율 계산에는 반영됩니다. 100% 기준 흩어짐은 기존 로컬 대시보드의 계산을 사용합니다.
